Chép Tệp Cài Đặt KPI-KTNN_MayChu11.zip Sang Máy Chủ 11

Tệp cài đặt nén duy nhất đã được đóng gói sẵn sàng tại máy tính cá nhân của anh ở đường dẫn:

D:\Anti_IDE\KPI-KTNN_MayChu11.zip

Chọn 1 trong 3 cách sau để chuyển sang máy chủ 10.41.97.11:

Cách A — Khuyên Dùng
Qua Remote Desktop (mstsc)
  1. Bấm Win + R, gõ mstsc rồi ấn Enter.
  2. Điền IP: 10.41.97.11 và đăng nhập.
  3. Tại máy của anh: Chọn file KPI-KTNN_MayChu11.zip và bấm Ctrl + C.
  4. Tại màn hình máy 11: Bấm Ctrl + V dán vào ổ D:\.
Cách B — Chia sẻ mạng
Qua Windows Network Share
  1. Bấm Win + R, gõ đường dẫn:
    \\10.41.97.11\d$
  2. Điền tài khoản/mật khẩu quản trị máy chủ.
  3. Kéo thả tệp .zip trực tiếp vào ổ D của máy chủ 11.
Cách C — Cục bộ
Qua Thiết bị USB
  1. Cắm USB vào máy đang ngồi và copy tệp KPI-KTNN_MayChu11.zip vào USB.
  2. Cắm USB trực tiếp vào máy chủ 11 và copy file ra ổ đĩa D:\.
2
Giải Nén & Mở Cổng Tường Lửa (Firewall 8080) Trên Máy Chủ 11

Thực hiện thao tác trực tiếp trên máy chủ 10.41.97.11:

2.1. Giải nén thư mục ứng dụng:

Nhấp chuột phải vào file KPI-KTNN_MayChu11.zip → Chọn Extract All... → Đặt thư mục giải nén là D:\KPI-KTNN.

2.2. Mở cổng 8080 trên Windows Firewall (Chỉ cần làm 1 lần duy nhất):

Mở menu Start trên máy chủ 11, tìm kiếm PowerShell → Nhấp chuột phải chọn Run as Administrator → Dán câu lệnh sau rồi ấn Enter:

New-NetFirewallRule -DisplayName "KPI-KTNN-8080" -Direction Inbound -LocalPort 8080 -Protocol TCP -Action Allow
💡
Lưu ý quan trọng:
Lệnh trên cho phép toàn bộ máy tính của 35 cán bộ trong mạng nội bộ KBNN gửi/nhận số liệu KPI qua cổng 8080 mà không bị Windows Defender chặn.

Khởi Động Ứng Dụng & Thiết Lập Tự Bật Cùng Windows

3.1. Khởi động ứng dụng ngay lập tức:

Mở thư mục D:\KPI-KTNN trên máy chủ 11, nhấp đúp vào tệp tin thực thi:

start_lan_server.bat

3.2. Mẹo cấu hình tự động bật khi khởi động máy chủ (Auto-start):

  • ✓
    Nhấp chuột phải vào file start_lan_server.bat → Chọn Show more options → Chọn Create shortcut.
  • ✓
    Bấm tổ hợp phím Win + R, gõ lệnh shell:startup rồi ấn Enter để mở thư mục khởi động của Windows.
  • ✓
    Kéo file Shortcut vừa tạo thả vào thư mục này. Từ nay, mỗi khi máy chủ khởi động lại hoặc có điện lại sau sự cố, hệ thống KPI sẽ tự động chạy ngầm mà không cần ai phải mở thủ công!
